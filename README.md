# Quantitative Simulations & Algorithms

This repository contains Python scripts focused on statistical simulations, financial modeling, and algorithmic problem-solving, built as part of my preparation for Quantitative Trading roles.

## Projects Included

### 1. Random Walk Market Simulation (`random_walk_simulation.py`)
A basic Monte Carlo simulation of a financial asset's price movement.
- **Concepts Used:** Random walks, normal distribution ("numpy.random.normal"), statistical analysis (mean, standard deviation, max/min), and data visualization with "matplotlib".
- **Purpose:** To understand the stochastic nature of financial markets and practice statistical modeling.

### 2. Luhn Algorithm Validator (`luhn_algorithm_validator.py`)
A script to validate credit card numbers using the Luhn Algorithm (Modulus 10).
- **Concepts Used:** String manipulation, array slicing, basic arithmetic operations, and algorithmic logic.
- **Purpose:** To practice clean algorithmic problem solving and data validation.
